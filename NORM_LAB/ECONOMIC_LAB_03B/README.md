# NORM 03B — isolated public-data economic evidence (V1)

**Scope:** independent M6 maker-market-microstructure data route, **research/read-only**. Exists alongside, not instead of, M1 native MOEX/Finam calendar research. No Floot, credentials, orders, client data, VPS, margin accounts or Forex changes.

**Bounded source:** the **public** Kraken WebSocket v2 `book` (L2 with required CRC32 check) and `trade` (unique trade IDs), three explicit public spot pairs, at most 150 seconds in the scheduled workflow. Exchange-event and local-receipt timestamps are recorded independently in an ephemeral runner file, with SHA256 fingerprint. Feed geography, network access and broker/client eligibility are **not** assumed.

**Isolation:** `.github/workflows/norm-03b-public-readonly.yml` has `contents: read`, no GitHub write permission, no secrets, no authenticated endpoints, no raw tape artifact. Old workflows and `norm-arb-r01` remain unchanged. Actions logs/artifacts contain aggregate-only screening counts and fingerprint; raw bytes are destroyed after replay. No GitHub runner is automatically authorized to write Google Drive. A raw hash without raw storage is *not independently replayable evidence*.

**M6 test protocol:** require correct CRC book, local-receipt causality, book snapshot then updates, fixed 300ms modeled latency, visible nonmarketable posted limit, **trade THROUGH bid** after posting with a fresh exchange timestamp (not same-price trade, quote-touch or last). Conservative exit at observed bid depth after 10s; missed, censored and invalid books explicitly counted. Broker-specific fills/queue and actual order identity remain unobserved: `CLOSED_PROXY` is **not** a fill and never EXECUTABLE_CLOSED_CYCLE. Public fee scenario from Kraken `0.38% maker/0.80% taker` is not user-account pricing. USD 100 model notional and 14% illustrative opportunity APR are not the canonical NORM 10,000 RUB portfolio with 2,000 RUB reserve.

**Decision:** `MODEL_SCREEN_NOT_EXECUTABLE` even if a modeled after-cost sum happens to be positive; if no verified L2 data then `DATA_BLOCKED`. Do not promote to OOS, PAPER or LIVE. Positive evidence needs eligible venue/account, verified true tariff, independent forward days, actual trade queue/participant order IDs or stronger defensible queue analysis, permanent permitted raw tape, real financing on total linked capital, and >=30 independent closed shadow cycles/3 days. Snapshot and synthetic tests never prove trading profitability.

**M1** remains `DATA_BLOCKED` for private Finam route/fee/margin/native spread/real-time WS without separately approved secure infrastructure. **M2** remains separate with legal/account eligibility gating; M3/M4/M5 preserve their previous decision status. Research cannot transfer Floot secrets. Do not publish account data or private trading signals.

**Sources:** [Kraken L2](https://docs.kraken.com/exchange/api-reference/spot-websocket-v2/book), [Kraken trades](https://docs.kraken.com/exchange/api-reference/spot-websocket-v2/trade), [official CRC guide](https://docs.kraken.com/exchange/guides/websockets/book-checksum-v2), [published fee schedule](https://www.kraken.com/features/fee-schedule), [03B original contract](https://docs.google.com/document/d/1fp6d7cawFU_UEEtJKy6J-BI19jvp5zDCkVe-oe0T3EU/edit).

Run locally: `python -m unittest discover -s tests -v`; `python -m pip install websockets`; `python research.py capture --seconds 150`; `python research.py replay --path 03b_ephemeral_capture.jsonl`. Never commit the resulting JSONL. Experimental observations are not investment advice.
