# ЭТрН — Госключ · R2 FIX2

## Текущий статус: водительские испытания приостановлены

Решение от 18.09.2026. Не распространять очередные исправления как готовый продукт и не просить водителя повторять опыт после каждой правки. Прежняя рекомендация провести повторный тест FIX2 отозвана. Изменение этой инструкции не отключает ранее установленные APK и не отзывает файлы с Google Drive.

Текущий APK — исследовательский пробник. Он не завершает документооборот и не является готовым массовым подписанием. Источники и диагностические результаты сохраняются; производство новых водительских сборок не является следующим шагом. Этот коммит меняет только документацию, не код приложения.

## Доказанное и недоказанное

По полученным журналам подтверждены вход в личный Saby, чтение документов и успешная подготовка по одному подписываемому вложению для двух разных ЭТрН после подтверждения реквизитов. Запрос Create в FIX1 остановился на отсутствии аргумента Params. Живой успешный Create, доставка одного пакета из разных ЭТрН в Госключ, подписи всех файлов, возврат результатов в каждый исходный документ и завершение нужных этапов не подтверждены.

Прохождение синтетических тестов, валидный APK и идентификатор криптооперации не являются доказательством конечного результата. Документация Saby описывает DocumentID и Files, но доступный текст не подтверждает явно, что Files может включать вложения разных документов. Эту неопределённость нельзя объявлять закрытой собственным mock-сервером.

## Условия продолжения без использования водителей как тестировщиков

1. Ревизия всего пути, а не очередной точечный патч: авторизация, роли и привязка ЕСИА, получение полного списка, точный выбор этапа и действия, реквизиты, подготовка, криптооперация, получение и сопоставление подписей, завершение по каждому документу, повторное чтение и подтверждение результата. Не угадывать отсутствующие схемы, поля и статусы.
2. На стороне разработки: независимые от реализации проверки запросов по первичным контрактам; регрессии известных ошибок; сценарии пустых полей, смены аккаунта, нескольких страниц, истечения сессии, обрыва связи и частичного результата; установка, запуск и переходы на Android; журнал, позволяющий локально воспроизводить уже полученные ошибки. Обезличенные реальные ответы и синтетические данные учитывать отдельно.
3. До выпуска потребительского интерфейса нужно обоснование самого пакетного маршрута для РАЗНЫХ ЭТрН: точная документация либо ответ оператора по этой схеме и, где требуется, разрешённый интеграционный стенд. Доступность такого стенда для проекта пока не установлена. Не использовать производственные документы или чужую подпись без отдельного разрешения.
4. Результат для пользователя — не OperationID и не надпись PACKAGE READY, а корректно завершённый нужный этап каждой выбранной ЭТрН после подписания владельцем ключа. Не масштабировать лимит 2 до 50, пока не решены корректность сопоставления и восстановления.
5. Возвращение к владельцу подписи — только после доказательств по доступным разработчику этапам и отдельного согласования ограниченной приёмки, а не как автоматический следующий шаг после сборки. Не обещать, что одна приёмка гарантированно исключит все будущие дефекты. При провале приёмки остановить опыт; не назначать новую установку автоматически.
6. Нет подтверждённого маршрута или необходимого изолированного контура — фиксировать инфраструктурный блокер и приостановить интеграцию, а не переносить отладку на водителей. Не объявлять техническую невозможность только по ошибке запроса.

## Техническое состояние FIX2 — сохранено для разработки

Для `sabyCryptoOperation.Create` построитель сейчас содержит `params.Params.Operation`; для `sabyCryptoOperation.GetStatus` — `params.Params.OperationID`. Исправление находится в `SabyRpcContract`. Авторизация, профиль, чтение и подготовка не оборачиваются. Эти структуры требуют проверки по первичному контракту целиком; синтетические тесты подтверждают только то, что проверяют их утверждения.

Существующие ограничения: первая страница событий списка; подтверждение реквизитов; один Create после согласия; нет автоматического перезапуска Create при неопределённом результате; `СБИС.ВыполнитьДействие` не вызывается. OperationID не означает успешного подписания обоих документов. Ключ установки — тестовый Android-ключ CI, не электронная подпись водителя.
