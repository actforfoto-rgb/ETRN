# ETRN_GOSKEY_BATCH_PROBE_R1

Узкий диагностический Android-пробник для проекта ЭТрН.

## Единственный Gate

Проверить, примет ли официальный метод Saby `sabyCryptoOperation.Create` одну криптооперацию Госключа, если:

- `DocumentID` относится к ЭТрН A;
- `Files[0].AttachmentID` относится к ЭТрН A;
- `Files[1].AttachmentID` относится к **другой ЭТрН B**.

Если сервер создаст один `OperationID`, следующий фактический вопрос — что покажет Госключ: один пакет с обоими файлами или иной результат.

## Что приложение делает

1. Авторизуется методом `СБИС.Аутентифицировать`.
2. Может проверить привязку ЕСИА через `СБИС.ИнформацияОТекущемПользователе`.
3. Вызывает **ровно один** `sabyCryptoOperation.Create` с двумя `AttachmentID`.
4. Показывает полный ответ сервера и извлекает `OperationID`, если он есть.
5. Позволяет вызвать `sabyCryptoOperation.GetStatus`.

## Чего приложение НЕ делает

- не использует внутренний `ExternalCertificate.InitOperation`;
- не вызывает `СБИС.ВыполнитьДействие`;
- не проводит ЭТрН на следующий этап;
- не хранит пароль или Saby-session на диске;
- не отправляет учетные данные никуда, кроме официального `online.sbis.ru`.

## Важно

`Create` создаёт реальный запрос на подпись в Госключ. По документации Saby такой запрос нельзя отозвать через API. Gate выполняется только на двух ЭТрН, действительно ожидающих подписи этого водителя.

## Сборка

GitHub Actions собирает debug APK и публикует artifact `ETRN_GOSKEY_BATCH_PROBE_R1`.
