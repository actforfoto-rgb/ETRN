# ETRN_GOSKEY_BATCH_PROBE_R1

Технический пробник проекта ЭТрН для единственного Gate: может ли официальный `sabyCryptoOperation.Create` создать одну операцию Госключа, если `DocumentID` относится к ЭТрН A, а `Files` содержит подготовленные к подписи `AttachmentID` сразу от ЭТрН A и ЭТрН B.

R1 использует только документированные API Saby (`sabyCryptoOperation.Create` / `GetStatus`). Внутренний `ExternalCertificate.InitOperation` в исполняемом коде не используется.

Приложение диагностическое: оно не вызывает `СБИС.ВыполнитьДействие`, не проводит ЭТрН дальше по документообороту и не сохраняет логин/пароль/Saby-session на диск.

`Create` создаёт реальный запрос на подпись в Госключ; выполнять Gate следует только на двух ЭТрН, которые действительно ждут подписи этого водителя.
