# ЭТрН — Госключ · R2 FIX2

Пилот для одного водителя-ИП и двух ЭТрН. Не завершает документооборот и не является готовым массовым подписанием.

## Что показал живой FIX1

Профиль и 16 документов прочитаны. Для двух выбранных ЭТрН успешно подготовлено по одному подписываемому вложению. Create вернул: `При вызове метода "sabyCryptoOperation.Create" не передан аргумент "Params"!`. Это ошибка формирования запроса приложения; проверка поддержки двух разных ЭТрН сервером ещё не состоялась.

## Изменение FIX2

Для `sabyCryptoOperation.Create` JSON-RPC теперь содержит `params.Params.Operation`; для `sabyCryptoOperation.GetStatus` — `params.Params.OperationID`. Внешнее поле JSON-RPC `params` и именованный аргумент метода `Params` — разные уровни. Исправление находится в общем проверяемом построителе `SabyRpcContract` и применяется только к этим двум методам. Авторизация, профиль, чтение и подтверждённая живым тестом подготовка не оборачиваются. 12 новых синтетических тестов проверяют сериализованный запрос вместе с 22 тестами реквизитов FIX1. Прохождение этих тестов не означает успешного живого Create.

Существующие ограничения сохраняются: только первая страница событий списка; реквизиты нужно подтвердить; один Create после отдельного согласия; повторные Create и неопределённые результаты не перезапускаются автоматически; `СБИС.ВыполнитьДействие` не вызывается; OperationID не означает успешного подписания обоих документов. Сессия и пароль не сохраняются на диск, секреты и двоичные файлы не передаются в диагностике.

## Повторный тест после ошибки отсутствующего Params

Скачать FIX2, удалить только наш прежний APK при несовместимой подписи установки. Saby и Госключ не трогать. Сначала убедиться, что в Госключе нет незавершённого запроса от другого запуска. Войти, выбрать две ЭТрН, подтвердить реквизиты и подготовить. Создать один запрос, проверить Госключ и статус, затем «Скопировать лог» → Telegram → вставить → отправить. При ошибке не повторять Create. Не снимать защиту переустановкой после тайм-аута или получения OperationID.

Ключ установки — тестовый Android-ключ CI; это не электронная подпись водителя.
