# Технические вопросы по Saby TMS → Госключ

Статус: черновик для уточнения. Оператору не отправлен. Не является обращением от имени компании. 18.09.2026.

Внешнее приложение работает под пользовательской сессией подписывающего водителя-ИП. Для двух разных ConsignmentNote через СБИС.ПодготовитьДействие получены два подписываемых вложения. Нужна одна операция Госключа с файлами обоих документов и корректное завершение по каждому исходному документу. Речь НЕ о нескольких вложениях одного документа и НЕ о штатной кнопке массовой обработки Saby.

1. Просим полный JSON-RPC запрос и ответ sabyCryptoOperation.Create для КЭП ИП. В таблице Params поле Operation не содержит типа и описания. Что передавать в Operation, на каком уровне расположить CertificateType, GoskeySignatureKind, GoskeyOgrnip, DocumentID и Files?

2. Разрешено ли включать в один запрос AttachmentID из двух РАЗНЫХ ConsignmentNote одного подписанта? Что указывать в единственном DocumentID? Если нет — есть ли другой документированный пакетный маршрут? Какие лимиты и требования к отправителям/этапам/действиям?

3. Нужны полные ответы GetStatus: ожидание, успех, отказ, истечение, частичный результат, ошибка. Как сопоставить каждую отсоединённую подпись с исходным AttachmentID? Возвращаются байты или ссылки; каковы сроки и правила чтения?

4. Подписи автоматически закрепляются за вложениями либо их нужно передать через СБИС.ВыполнитьДействие? Как закреплять редакцию и этап и не перегенерировать уже подписанные файлы? Как проверить завершение требуемого титула и приём ГИС ЭПД?

5. Нужен изолированный тестовый контур TMS + Госключ с отдельными тестовыми документами, пользователем и подписью без продуктивной ГИС ЭПД и рабочих водителей. Есть ли такой контур, как получить доступ и какие точные адреса? Старое упоминание fix-online само по себе не подтверждает эту возможность.

6. Поддерживается ли СБИС.СписокДокументов для ConsignmentNote на tms.saby.ru/service/ с ДатаС/ДатаПо и страницами? Если нужен СБИС.СписокИзменений, как получить полный набор по дате ДОКУМЕНТА, а не только по событиям этой даты?

7. Какие роли и привязка ЕСИА нужны отдельному пользователю ИП? Как выяснить результат Create после тайм-аута без полученного OperationID и без повторной отправки? Есть ли ключ идемпотентности/поиск существующей операции?
